# AI Copilot Playbook — Project Files

Everything you need to build your company's AI hub. Use these files to populate SharePoint and OneNote.

---

## Files in This Folder

| File | What It's For | Use It To... |
|------|--------------|--------------|
| `01-sharepoint-build-guide.md` | Full step-by-step SharePoint setup | Follow this to build the site from scratch |
| `02-starter-prompt-library.md` | 50 curated Copilot prompts | Copy into your SharePoint Prompt Library list |
| `03-learning-paths.md` | Beginner → Advanced learning paths | Paste into your Learn page in SharePoint |
| `04-onenote-journal-template.md` | Personal AI Journal template | Each pilot user copies this into their OneNote |
| `05-governance-content.md` | Responsible AI & governance policy | Paste into your SharePoint Governance page |
| `06-starter-use-cases.md` | 10 real use cases with step-by-step guides | Load these into your Use Cases Gallery list |
| `07-agents-tools-directory.md` | Tool guide for all Copilot tools | Paste into your Agents & Tools Directory page |
| `08-gamification-monthly-challenge.md` | Points system + 12-month challenge bank | Use for your Community page and Leaderboard |

---

## Recommended Build Order

1. **Create the SharePoint site** → follow `01-sharepoint-build-guide.md` completely
2. **Load the Prompt Library** → copy prompts from `02-starter-prompt-library.md` into the list
3. **Build the Learn page** → use content from `03-learning-paths.md`
4. **Set up Governance page** → copy from `05-governance-content.md` (replace placeholders)
5. **Load Use Cases** → copy from `06-starter-use-cases.md` into the list
6. **Build Agents & Tools page** → copy from `07-agents-tools-directory.md`
7. **Set up Community page** → copy from `08-gamification-monthly-challenge.md`
8. **Share OneNote template** → give `04-onenote-journal-template.md` to each pilot user

---

## Placeholders to Replace

Before publishing any content, search for and replace:
- `[Company Name]` → your actual company name
- `[AI Guru name]` → your name
- `[IT Contact]` → your IT helpdesk contact
- `[Date]` → today's date
- `[form link]` → your Microsoft Forms URL (after you create the forms)

## Quick Stats Goal (End of Pilot)

By the end of your 2–3 week pilot, aim to have:
- [ ] 5+ pilot users active
- [ ] 15+ prompts in the library (10 starter + 5 from team)
- [ ] 3+ use cases submitted
- [ ] 2+ certifications logged on the wall
- [ ] Everyone has their OneNote journal set up
- [ ] At least 1 monthly challenge completed
