# Starter Prompt Library — AI Copilot Playbook

50 curated prompts to seed your Prompt Library. Copy each into your SharePoint list.
Each prompt includes: Title | Category | Tool | The Prompt

---

## WRITING

**1. Executive Summary Writer**
- Tool: Copilot (General)
- Prompt: `Write a concise executive summary (max 150 words) of the following document. Focus on key findings, recommendations, and next steps: [paste document text]`

**2. Email Tone Improver**
- Tool: Outlook Copilot
- Prompt: `Rewrite this email to sound more professional and concise while keeping the core message. Remove any passive-aggressive tone: [paste email]`

**3. Meeting Agenda Creator**
- Tool: Copilot (General)
- Prompt: `Create a structured 60-minute meeting agenda for a [topic] meeting with [number] attendees. Include time slots, discussion points, and desired outcomes for each section.`

**4. Status Update Writer**
- Tool: Copilot (General)
- Prompt: `Write a weekly status update for my manager based on these bullet points. Make it professional, highlight wins, and flag any blockers: [paste your bullet points]`

**5. Job Description Writer**
- Tool: Copilot (General)
- Prompt: `Write a clear, inclusive job description for a [job title] role at a [industry] company. Include: role overview, key responsibilities (5-7), required skills, and what we offer. Avoid jargon.`

**6. Blog Post Outline**
- Tool: Copilot Researcher
- Prompt: `Create a detailed blog post outline for the topic: "[your topic]". Include an engaging title, 5 main sections with 3 sub-points each, and a compelling conclusion with a call to action.`

**7. Presentation Narrative**
- Tool: Copilot (General)
- Prompt: `I have a presentation with these slides: [list slide titles]. Write a compelling spoken narrative (2-3 sentences per slide) that flows naturally between topics and tells a coherent story.`

## How to Add These to SharePoint

1. Go to your `Prompt Library` SharePoint list
2. Click **+ New** for each prompt
3. Fill in: Title, The Prompt text, Category, Tool, Role/Use Case
4. Set `Verified by AI Guru` = Yes for these starter prompts
5. You can also bulk import via Excel: Download list → paste all entries → import back

> Tip: Use Copilot Analyst to help you reformat these entries into a spreadsheet for bulk import!
